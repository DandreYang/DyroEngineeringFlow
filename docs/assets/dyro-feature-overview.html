DyroEngineeringFlow · dyro CLI

功能总览 · 可视化

本地优先的多仓交付控制面：开发线 · worktree · Agent 启动 · 门禁 · 独立复核 · 合并审计。 Agent 只负责干活，证据与放行权在 Dyro。

01 · 分层架构

Profile
团队配置

策略层 · dyro.toml

repositories layout / bases Agent adapter argv gates / 回执模板 policy
Core
机制

Dyro CLI · 不绑业务与模型

workspace / lines launch dispatch · DAG verify · gates merge · push 策略 home / console
Runtime
.dyro/

运行态 · 可审计

tasks / lines evidence · receipt review · signoff ledger.jsonl changesets

Core 只提供机制；业务规则、模型成本、发布实践始终留在 Profile。

02 · 本地交付链路

1setup / join工作区就绪
→
2line create开发线
→
3task createworktree
→
4run + gates编排器验证
→
5review绑定 HEAD
→
6merge合入开发线

门禁由 Dyro 实际执行；Agent 自报不算证据。复核绑定 receipt 与各仓精确 task HEAD。

03 · 任务状态机

backlog → assigned → in_progress → review → done
waiting_answer ↔ in_progress failed → re-claim review_pending_signoff → done

非法跳转被拒绝；done 只能由已验证证据 + 独立复核（+ 可选签收）写入，不能靠 force 硬推。

04 · 八大能力

📁

多仓工作区

anchors、开发线、Hotfix、逐仓 base 与隔离 worktree。

🕸️

任务图调度

depends_on、blocked_on、conflict_group；next / loop / daemon。

✅

门禁与证据

编排器跑 gates；attempt / receipt / task-heads 可追溯。

🔍

独立复核

复核绑定回执与 HEAD；漂移即失效；可选外部签收。

📦

外部执行包

claim 租约 + evidence ZIP；控制面只校验不代跑。

🔐

签名与 Witness

Ed25519 信任库、用途分离、远程不可变审计回执。

🏠

Home / Console

任意目录入口；只读本地仪表盘，无网络写操作。

🧩

Dispatch 实验

本地多 Agent 派发仅作建议，不替代 gates / merge。

05 · 执行模式对比

local · 本机闭环

  • 本机 adapter 启动 Agent
  • 本机执行 gates / review / merge
  • 适合个人与小团队日常交付

external · 隔离 runner

  • 控制机仅 claim / 导入证据
  • runner 打包 receipt + heads
  • 可强制签名执行 / 复核 / 签收
